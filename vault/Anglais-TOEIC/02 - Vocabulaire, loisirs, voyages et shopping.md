# Vocabulaire, loisirs, voyages et shopping

> [!abstract] L'essentiel en 30 secondes
> - Au TOEIC, on rencontre souvent : **horaires, billets, réservations, menus, prix, soldes**.
> - *Fare* = prix du trajet ; *price* = prix d'un objet ; *bill* (UK) / *check* (US) = l'addition.
> - *Return ticket* = aller-retour ; *one-way ticket* = aller simple.

## Le cours

### 1. Loisirs et sport

| Anglais | Français |
|---|---|
| a hobby | un loisir |
| to go hiking / cycling | faire de la randonnée / du vélo |
| to play chess | jouer aux échecs |
| a match / a team | un match / une équipe |
| to win / to lose | gagner / perdre |
| a concert, a film, an exhibition | un concert, un film, une exposition |
| to be keen on | être passionné de |

### 2. Voyages et transports

| Anglais | Français |
|---|---|
| a flight / a plane | un vol / un avion |
| an airport, a gate | un aéroport, une porte d'embarquement |
| a platform | un quai |
| delayed / cancelled | en retard / annulé |
| a timetable / a schedule | un horaire |
| luggage / baggage | bagages |
| to book / a booking | réserver / une réservation |
| a passport | un passeport |
| to miss the bus | rater le bus |

### 3. Hôtel et restaurant

| Anglais | Français |
|---|---|
| a single / double room | une chambre simple / double |
| to check in / to check out | arriver / partir de l'hôtel |
| a menu, a starter, a main course, a dessert | un menu, une entrée, un plat, un dessert |
| a waiter / a waitress | un serveur / une serveuse |
| the bill | l'addition |
| a tip | un pourboire |
| vegetarian | végétarien |

### 4. Magasins et argent

| Anglais | Français |
|---|---|
| a shop assistant | un vendeur |
| a sale | des soldes |
| cheap / expensive | bon marché / cher |
| a discount | une réduction |
| a receipt | un reçu, un ticket de caisse |
| to refund | rembourser |
| cash / by card | en liquide / par carte |
| It costs / It's worth | Ça coûte / ça vaut |

> [!warning] Piège
> *Cheap* n'est pas péjoratif ici : c'est « pas cher ». *To pay for* + chose : *I paid for the ticket.* *Travel* est indénombrable : *a trip* / *a journey* pour un voyage précis.

## Exercices corrigés

> [!question] Exercice 1
> You see: *Flight BA204 – DELAYED – new departure 18:40.* Le vol part-il à l'heure ?

> [!success]- Corrigé
> **Non**, il est en retard (*delayed*), nouveau départ à 18 h 40.

> [!question] Exercice 2
> Complète : *Could I have the ____, please?* (l'addition)

> [!success]- Corrigé
> **bill** (UK) ou **check** (US).

## Quiz

```quiz
? « A return ticket » :
- aller simple
+ aller-retour
- billet annulé
> One-way = aller simple.

? « Delayed » :
- annulé
+ en retard
- complet
> Cancelled = annulé.

? « To check in » à l'hôtel :
+ s'enregistrer à l'arrivée
- payer
- partir
> Check out = partir.

? « A receipt » :
- une recette
+ un reçu
- une réception
> Faux ami : receipt n'est pas une recette (recipe).

? « A sale » :
+ des soldes
- une salle
- une vente de voiture
> Sale = soldes, promotions.

? « A tip » au restaurant :
- une astuce seulement
+ un pourboire
- un menu
> Tip veut dire aussi « astuce ».
```

```quiz Réponds en anglais
? « bagages » (un mot) ?
= luggage

? « réserver » ?
= book

? « bon marché » ?
= cheap
```
