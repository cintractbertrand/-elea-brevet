## Comment réviser avec une fiche

1. Lire l'encadré **L'essentiel en 30 secondes**.
2. Relire **le cours** et les **exemples**.
3. Faire les **exercices** sans regarder le corrigé, puis vérifier.
4. Faire le **quiz** (sur le site, il est interactif).
5. Regarder une **vidéo** si une notion reste floue.

## Le site de révision

Double-clique sur **« Lancer le site.bat »** (dans le dossier *elea brevet*, à côté de ce coffre) : le site s'ouvre dans le navigateur avec les fiches, la recherche, les quiz et les vidéos. Tout ce qui est modifié ici dans Obsidian apparaît sur le site en rechargeant la page.
