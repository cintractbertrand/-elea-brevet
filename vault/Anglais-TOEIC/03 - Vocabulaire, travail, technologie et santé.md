# Vocabulaire, travail, technologie et santé

> [!abstract] L'essentiel en 30 secondes
> - Le TOEIC aime les textes de **bureau** : mails, réunions, annonces, offres d'emploi.
> - *Meeting* = réunion ; *deadline* = date limite ; *to apply for a job* = postuler.
> - Formules de mail : *Dear Sir/Madam*, *Best regards*, *Please find attached…*

## Le cours

### 1. Travail

| Anglais | Français |
|---|---|
| a job / work | un emploi / le travail |
| a manager / a colleague | un responsable / un collègue |
| an employee / an employer | un employé / un employeur |
| an interview | un entretien d'embauche |
| to apply (for) | postuler |
| a salary / wages | un salaire |
| a deadline | une date limite |
| part-time / full-time | à temps partiel / plein |
| to hire / to fire | embaucher / licencier |
| a meeting | une réunion |

### 2. Mails et communication

| Anglais | Français |
|---|---|
| Dear Mr Smith, | Cher Monsieur Smith, |
| Best regards / Yours sincerely | Cordialement |
| Please find attached… | Veuillez trouver ci-joint… |
| I am writing to… | Je vous écris pour… |
| to reply / to forward | répondre / transférer |
| an appointment | un rendez-vous |
| to cancel / to postpone | annuler / reporter |
| as soon as possible (ASAP) | dès que possible |

### 4. Santé

| Anglais | Français |
|---|---|
| a doctor / a nurse | un médecin / un infirmier |
| a pharmacy / a chemist's | une pharmacie |
| a headache, a sore throat | un mal de tête, un mal de gorge |
| a fever / a cold | de la fièvre / un rhume |
| to feel sick / dizzy | avoir la nausée / des vertiges |
| medicine | des médicaments |
| to take a rest | se reposer |

> [!warning] Piège
> *Postpone* = **reporter** (déplacer à plus tard), *cancel* = **annuler**. *Interview* = entretien. *Sensible* n'est pas « sensible ». *Eventually* = finalement, pas « éventuellement ».

## Exercices corrigés

> [!question] Exercice 1
> *Mr Lee writes: "The meeting is postponed to Friday."* La réunion est-elle annulée ?

> [!success]- Corrigé
> **Non**, elle est reportée à vendredi.

> [!question] Exercice 2
> Complète : *Please ____ the attached file.* (trouver ci-joint) → « Please find the attached file. »

> [!success]- Corrigé
> **find**.

## Quiz

```quiz
? « Deadline » :
- la fin de la journée
+ la date limite
- un salaire
> Deadline = date limite.

? « To postpone » :
+ reporter
- annuler
- accepter
> Cancel = annuler.

? « To apply for a job » :
- licencier
+ postuler
- embaucher
> Apply for = postuler à.

? « Please find attached » :
- Je ne trouve pas la pièce jointe
+ Veuillez trouver ci-joint
- Retrouve-moi
> Formule classique des mails.

? « A sore throat » :
+ un mal de gorge
- une gorge rouge
- une toux
> Sore = douloureux.

? « To download » :
- envoyer en ligne
+ télécharger
- supprimer
> Upload = envoyer.
```
