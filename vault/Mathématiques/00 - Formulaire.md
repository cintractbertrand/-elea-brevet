# Formulaire

## Calcul

| Notion | Formule |
|---|---|
| Fractions | $\dfrac{a}{b} + \dfrac{c}{b} = \dfrac{a + c}{b}$ ; $\dfrac{a}{b} \times \dfrac{c}{d} = \dfrac{ac}{bd}$ ; $\dfrac{a}{b} \div \dfrac{c}{d} = \dfrac{a}{b} \times \dfrac{d}{c}$ |
| Puissances | $a^m \times a^n = a^{m+n}$ ; $\dfrac{a^m}{a^n} = a^{m-n}$ ; $(a^m)^n = a^{m \times n}$ ; $a^{-n} = \dfrac{1}{a^n}$ ; $a^0 = 1$ |
| Écriture scientifique | $a \times 10^n$ avec $1 \leq a < 10$ |
| Distributivité | $k(a + b) = ka + kb$ ; $(a + b)(c + d) = ac + ad + bc + bd$ |
| Identités remarquables | $(a + b)^2 = a^2 + 2ab + b^2$ ; $(a - b)^2 = a^2 - 2ab + b^2$ ; $(a + b)(a - b) = a^2 - b^2$ |
| Équation-produit | $A \times B = 0 \iff A = 0$ ou $B = 0$ |
| Pourcentages | hausse de $t\,\%$ : $\times \left(1 + \dfrac{t}{100}\right)$ ; baisse de $t\,\%$ : $\times \left(1 - \dfrac{t}{100}\right)$ |

Détails : [[01 - Nombres relatifs et fractions]], [[02 - Puissances et notation scientifique]], [[04 - Calcul littéral]], [[05 - Équations]].

## Fonctions et données

| Notion | Formule |
|---|---|
| Fonction affine | $f(x) = ax + b$ ; $a = \dfrac{f(x_2) - f(x_1)}{x_2 - x_1}$ |
| Fonction linéaire | $f(x) = ax$ (proportionnalité) |
| Moyenne pondérée | $\dfrac{v_1 n_1 + v_2 n_2 + \ldots}{n_1 + n_2 + \ldots}$ |
| Étendue | $\max - \min$ |
| Fréquence | $\dfrac{\text{effectif}}{\text{effectif total}}$ |
| Probabilité (équiprobabilité) | $P(A) = \dfrac{\text{issues favorables}}{\text{issues possibles}}$ ; $P(\overline{A}) = 1 - P(A)$ |

## Géométrie plane

| Notion | Formule |
|---|---|
| Pythagore (rectangle en $A$) | $BC^2 = AB^2 + AC^2$ |
| Thalès ($(MN) \parallel (BC)$) | $\dfrac{AM}{AB} = \dfrac{AN}{AC} = \dfrac{MN}{BC}$ |
| Trigonométrie | $\cos = \dfrac{\text{adj}}{\text{hyp}}$ ; $\sin = \dfrac{\text{opp}}{\text{hyp}}$ ; $\tan = \dfrac{\text{opp}}{\text{adj}}$ |
| Agrandissement / réduction de rapport $k$ | longueurs $\times\, k$ ; aires $\times\, k^2$ ; volumes $\times\, k^3$ |
| Somme des angles d'un triangle | $180^\circ$ |

## Périmètres et aires

| Figure | Périmètre | Aire |
|---|---|---|
| Carré de côté $c$ | $4c$ | $c^2$ |
| Rectangle $L \times \ell$ | $2(L + \ell)$ | $L \times \ell$ |
| Triangle | somme des côtés | $\dfrac{\text{base} \times \text{hauteur}}{2}$ |
| Parallélogramme | somme des côtés | $\text{base} \times \text{hauteur}$ |
| Losange | $4c$ | $\dfrac{D \times d}{2}$ |
| Trapèze | somme des côtés | $\dfrac{(B + b) \times h}{2}$ |
| Disque de rayon $r$ | $2 \pi r$ | $\pi r^2$ |

## Volumes

| Solide | Volume |
|---|---|
| Pavé droit | $L \times \ell \times h$ |
| Prisme droit / cylindre | $\mathcal{B} \times h$ (cylindre : $\pi r^2 h$) |
| Pyramide / cône | $\dfrac{\mathcal{B} \times h}{3}$ (cône : $\dfrac{\pi r^2 h}{3}$) |
| Boule | $\dfrac{4}{3} \pi r^3$ ; aire de la sphère : $4 \pi r^2$ |

($\mathcal{B}$ = aire de la base.)

## Grandeurs

| Notion | Formule |
|---|---|
| Vitesse | $v = \dfrac{d}{t}$ ; $d = v \times t$ ; $t = \dfrac{d}{v}$ |
| km/h vers m/s | $\div\, 3{,}6$ |
| Contenances | $1 \text{ dm}^3 = 1 \text{ L}$ ; $1 \text{ cm}^3 = 1 \text{ mL}$ ; $1 \text{ m}^3 = 1\,000 \text{ L}$ |
| Durées | 1 h = 60 min = 3 600 s ; 0,1 h = 6 min |
